# نظام تحليل وتقييم مشاريع الطاقة الشمسية الكهروضوئية (Solar PV Feasibility Calculator)

## 1. وصف المسألة الهندسية وتخصصها
* **التخصص:** الهندسة الكهربائية / هندسة الطاقة المتجددة.
* **المسألة:** في مشاريع تصميم أنظمة الطاقة الشمسية الكهروضوئية (Solar PV)، يُعد تقييم الجدوى الفنية والاقتصادية أمراً أساسياً لتحديد السعة المناسبة، حساب كمية الطاقة المنتجة سنوياً، ومعرفة مدى جدوى الاستثمار من خلال حساب فترة استرداد رأس المال (Payback Period).
* **المدخلات:**
  1. سعة النظام المقترحة بالكيلوواط (kW).
  2. متوسط ساعات الذروة الشمسية اليومية (Peak Sun Hours).
  3. سعر تعريفة استهلاك الكهرباء (ريال لكل kWh).
  4. التكلفة الإجمالية لتركيب النظام (SAR).
* **ما يحسبه البرنامج:** الطاقة اليومية والسنوية المتولدة مع أخذ كفاءة النظام بعين الاعتبار (Performance Ratio = 80%)، التوفير المالي السنوي، وفترة استرداد التكلفة بالسنوات.

---

## 2. الطريقة وكيفية التشغيل
* **المعادلات المستعملة:**
  1. $\text{Daily Energy (kWh)} = \text{Capacity (kW)} \times \text{Peak Sun Hours} \times \text{PR (0.80)}$
  2. $\text{Annual Energy (kWh)} = \text{Daily Energy} \times 365$
  3. $\text{Annual Savings (SAR)} = \text{Annual Energy} \times \text{Electricity Rate}$
  4. $\text{Payback Period (Years)} = \frac{\text{Total Installation Cost}}{\text{Annual Savings}}$

* **كيف يُشغّل البرنامج:**
  لتشغيل البرنامج محلياً، افتح موجه الأوامر (Terminal أو Command Prompt) في مجلد المشروع واكتب الأمر التالي:
  ```bash
  python solar_calculator.py
  ```

## 4. حدود الحل والافتراضات
* **الافتراضات:** يفترض البرنامج كفاءة تشغيلية ثابتة للنظام (Performance Ratio) تبلغ 80% لتغطية الفاقد في الأسلاك والعاكس (Inverter) وفقدان الكفاءة بسبب الحرارة أو الغبار.
* **ما لا يغطيه البرنامج:** لا يأخذ في الاعتبار تدهور الألواح السنوي (Degradation Rate الذي يتراوح بين 0.5% إلى 1% سنوياً)، ولا يحسب القيمة الزمنية للنقود (Net Present Value - NPV) أو معدل الفائدة للتبسيط الهندسي الأساسي.
